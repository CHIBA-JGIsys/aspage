Salesforce運用フロー - 2025/02/10 Update版

本サンプルでは以下の点を考慮し、新人メンバー（新規営業）とレギュラーメンバー（既存・非掲載案件も含む）のフローを可視化しています。

  • 新人は「新規アタック～受注」の各KPIを明確に
  • レギュラーは「継続率（更新）」および「非掲載・落ち案件の再アタック」を管理
  • 前回MTGで挙がった「掲載頻度」「媒体」「取引金額（単価/アベレージ）」などの抽出条件にも対応

1. 新規営業フロー（新人メンバー向け）

以下は 新規アタック → 新規アポ獲得 → 新規有効商談 → 新規審査回収 → 新規審査通過 → 新規入金 → 新規受注 の流れを、Salesforceステージやカスタム項目と連動して管理する例です。 ※前回MTGの要望により「アポ取得」を「新規アポ獲得」等に修正し、各ステップ名に「新規」を冠しています。

① 新規アタック

KPI:新規アタック数
Opp/Lead.Status = 'アタック済'
店舗担当者と初コンタクトできた時にカウント。
不在なら除外。

② 新規アポ獲得

KPI:新規アポ獲得数
Opp/Lead.Status = 'アポ取得'
日時が確定したらカウント。
イベント登録やステータス変更で管理。

③ 新規有効商談

KPI:新規有効商談数
Opp/Stage = '商談中'
実際にヒアリング & プラン提案ができた件数。
商談メモや添付資料の共有を徹底。

④ 新規審査回収

KPI:新規審査回収数
Opp/Stage = '審査書類回収'
審査書類の署名を受領し提出待ちの状態。
書類不備や提出忘れを防ぐ。

⑤ 新規審査通過

KPI:新規審査通過数
Opp/Stage = '審査通過'
メーカー等の最終OKを確認。
差し戻し対応時は別ステータスへ。

⑥ 新規入金確認

Opp/Stage = '入金待ち'
前金・後払いなど、入金日を確実に記録。

⑦ 新規受注

KPI:新規受注数
Opp/Stage = 'Closed Won'
掲載開始＝売上計上完了の目安。
金額(Amount)や実際の受注日(CloseDate)を確定。

2. 既存営業フロー（レギュラーメンバー）

レギュラーメンバーは 更新営業（=継続率UP） および 非掲載・落ち案件の再アタック や アップセル／クロスセル を行うイメージです。
Account（店舗） + Contract/Opportunity で更新管理するほか、過去の掲載頻度・取引金額（単価/アベレージ）などでリスト抽出し、アタック優先度を決定します。

流れ自体は「新規アタック～受注」と同様のステージ管理を行い、担当営業の変更履歴等も記録しておくと便利です。

まとめとポイント

  • 新人メンバーは「新規アタック→新規アポ→新規商談→新規審査→新規受注」のステップ管理が基本
  • レギュラーメンバーは「継続率（更新）」「非掲載・落ち案件の再アタック」「アップセル・クロスセル」も並行して運用
  • SalesforceのStage / Contract.EndDate / RecordType等で
    各ステップを明確化し、KPIダッシュボード化を検討
  • 掲載頻度・取引金額（単価/アベレージ）・担当履歴などを活用してリスト抽出・優先度判断

以上のフローにより、現場メンバーごとの進捗把握や
経営視点のKPI管理が一貫して行いやすくなります。
